# Invest Analyzer

股票分析 Skill，提供实时行情、技术指标分析和量价形态识别。

## 功能特性

- **实时行情**: 获取股票当前价格、涨跌幅、成交量、五档盘口等数据
- **K线数据**: 支持多种时间周期（5分钟、15分钟、1小时、日线）
- **技术指标**: MA、MACD、KDJ、RSI、BOLL、VOL_MA、OBV 等指标计算
- **量价形态**: 放量滞涨、OBV背离、缩量上涨、放量突破、回踩均线支撑、均线破位等信号识别
- **技术评级**: 基于双周期技术面规则给出买入/增持/持有/减持/卖出判断
- **一键快照**: 单次调用返回行情、日线/5分钟 K线、指标和技术评级

## 快速开始

### 安装

以 Claude Code 为例，首先进入 skills 目录：

```bash
cd ~/.claude/skills
git clone https://github.com/zhangyangx/invest-analyzer.git
```

### 使用方式

在支持 AI 编程助手的工具中（如 Claude Code），直接对话即可：

```
分析一下 600519
```

```
分析一下 贵州茅台
```

```
帮我看看 600759 支撑位在哪
```

### 支持的对话方式

| 用户输入 | AI 行为 |
|---------|---------|
| `分析 600519` | 行情 + 双周期技术分析 |
| `分析 贵州茅台` | 先搜索股票代码，再做技术分析 |
| `600519 怎么样` | 行情 + 双周期技术分析 |
| `600759 支撑位在哪` | 技术分析 + 重点关注均线支撑/破位 |

### 股票代码格式

- `600519` - 自动识别市场（上海）
- `sh600519` - 指定上海市场
- `sz000001` - 指定深圳市场
- `000001` - 自动识别市场（深圳）
